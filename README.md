# App do Mestre

Gestão para academias de artes marciais: alunos, turmas, presença (lista e QR Code), graduações, financeiro, loja, contratos e lembretes de WhatsApp.

- `index.html`: site de vendas
- `app.html` + `app.js`: painel (versão demo, dados salvos no `localStorage` do navegador)
- `config.js`: **preços, planos, WhatsApp, e-mail e CNPJ.** Edite aqui.
- `termos.html`: termos e privacidade (rascunho)

Abra `app.html?demo=1` para carregar dados de exemplo.
